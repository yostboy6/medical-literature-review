# Medical Literature Review

A reusable Codex skill by Connor Yost for medical literature reviews and meta-analysis workflows.

Six stages: **define, collect, screen, extract, compare, write**.

[Download the skill ZIP](https://github.com/yostboy6/medical-literature-review/raw/refs/heads/main/medical-literature-review-skill.zip)

## Use in Codex

1. Download and unzip the skill ZIP.
2. Put the medical-literature-review folder in ~/.codex/skills/ or your configured skills directory.
3. In a new Codex chat, ask: `Use $medical-literature-review to review [TOPIC] for [PURPOSE].`

## Use in ChatGPT

Create a project, attach your papers, and paste the project instructions from GPT-review-instructions.txt. Follow the spreadsheet’s six prompts. The ZIP is a Codex skill, not a ChatGPT custom GPT installer.

## Research quality

The skill covers narrative, scoping and systematic reviews, with statistical pooling when appropriate. It combines a video-inspired workflow with sources from Cochrane, PRISMA, PubMed, GRADE, risk-of-bias tool developers, university guidance, official product documentation and Reddit workflow discussions. Full methods and source references are inside the skill ZIP. The original recording is not distributed.

Verify citations and analysis-driving data against primary papers. Formal systematic reviews require appropriate human screening, data verification and appraisal. Meta-analysis requires compatible data and an executed, reproducible analysis.
